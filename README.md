# Golf Course Shot Visualizer

The Golf Course Shot Visualizer is an interactive golf course exploration and shot planning application that allows golfers to analyze iconic hole layouts, visualize hazards and landing zones, and simulate realistic golf shot trajectories in both 2D high-resolution satellite imagery and immersive Photorealistic 3D Maps. Designed as a real-time caddie and strategic simulation tool, the application leverages Google AI Studio full-stack capabilities alongside Google Maps Platform geospatial visualization to provide interactive ball flight tracing, elevation-aware flyovers, wind and lie modeling, and dynamic 3D camera controls for authentic course management.

## Google Maps Platform Products & Features

- Maps JavaScript API
- Photorealistic 3D Maps
- 3D Map Element (`Map3DElement`)
- 3D Marker Element (`Marker3DElement`)
- 3D Interactive Marker Element (`Marker3DInteractiveElement`)
- 3D Polyline Element (`Polyline3DElement`)
- Advanced Markers (`AdvancedMarkerElement`)
- Satellite and Hybrid Imagery
- Polylines
- Circles
